# جيبتك

Working surface: an Arabic personal pocket ledger for a calm daily check-in on iPhone, with a spacious desktop companion.

Visual signature: an illuminated pine leather pocket, embossed curves and copper coins. A curved balance panel references the physical pocket. Quiet ruled transaction lists and small receipt notches keep the rest disciplined.

Palette: pine #194C40, deep ink #172C25, porcelain #F7F8F2, mist #D9E9DB, copper #B97448, alert #A9382F. Dark surfaces #142820 and #1D352C, readable mist foregrounds.

Type: locally bundled Arabic variable Readex Pro for headings and body, system sans for tabular financial figures. Headings 24–36px, body 16px, labels 14px, metadata 12px. No external requests at runtime.

Layout: desktop right rail | flexible daily overview | compact upcoming column. Phone: greeting → pocket balance → quick actions → obligations → upcoming → five-item bottom navigation. All larger sections reachable from More.

Motion: 420ms screen entrances, 70ms card stagger, 160ms touch feedback, 650ms numerical interpolation, 6s restrained wallet float. All optional under prefers-reduced-motion. No auto carousels.

Review: generated skill recommendations of glass, blue, Latin-only fonts, and marketing hero were rejected as incompatible with this task. Use accessible dashboard hierarchy from the narrower recommendation and the original material direction above.
